# Contributing to Synapse 4D

We welcome contributions to make Synapse 4D the universal standard for AI cognitive memory!

## How to Contribute
1. Fork the repository.
2. Create your feature branch (`git checkout -b feat/amazing-pillar`).
3. Commit your changes (`git commit -m 'feat: add temporal graph pruning'`).
4. Push to the branch (`git push origin feat/amazing-pillar`).
5. Open a Pull Request.

## Code Standards
- Adhere to PEP 8 and use type hints.
- Keep memory consolidation operations sub-second whenever possible.
- Ensure all newly created files in templates follow YAML frontmatter and `[[Wikilink]]` conventions.
